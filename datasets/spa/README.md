# Spa braking analysis

Start with FINDINGS.md and open findings.html for the candidate chart.

Source CSV: https://huggingface.co/datasets/Nasim435/spa-francorchamps-lap-data/resolve/main/telemetry.csv
License: MIT. Preserve source attribution when distributing data. See summary.json for the exact CSV checksum used here.

Keep the 67 MB raw CSV outside Git. With pandas and numpy available:

```sh
python analysis/spa/analyze_spa.py /path/to/telemetry.csv
python analysis/spa/check_analysis.py /path/to/telemetry.csv
```

The analysis writes candidate_events.csv, event_windows.csv, channel_summary.csv, threshold_sensitivity.csv and summary.json. The HTML and narrative are reviewed presentation snapshots and are not regenerated by that command.

Use candidate_events.csv for the event menu and event_windows.csv for plots. Label every event “possible lock-up”; show the detection threshold and evidence. Window IDs correspond to the time-sorted event rows numbered from one.

The existing app requires Python >=3.13. This standalone analysis was executed with the installed Python 3.12 runtime; it does not establish app compatibility or a successful app deployment. No application dependency configuration was changed.
